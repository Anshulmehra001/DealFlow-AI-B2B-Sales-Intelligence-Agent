## 🎥 Recording Tips

### Equipment
- Use screen recording software (OBS, Loom, or QuickTime)
- Record in 1080p (1920x1080)
- Use a good microphone
- Record in a quiet environment

### Preparation
1. **Prepare test data**
   - Have sample leads ready
   - Create a few deals in different stages
   - Ensure MongoDB has data

2. **Practice the flow**
   - Rehearse 3-5 times
   - Time each section
   - Smooth transitions

3. **Visual polish**
   - Clean browser tabs
   - Hide personal information
   - Use dark mode for better contrast

### Recording Checklist
- [ ] Close unnecessary applications
- [ ] Disable notifications
- [ ] Clear browser history/cache
- [ ] Test audio levels
- [ ] Have script visible on second monitor
- [ ] Record in one take if possible

### Editing
- Add background music (subtle, non-distracting)
- Add text overlays for key metrics
- Speed up slow parts (1.2x-1.5x)
- Add transitions between sections
- Export in MP4 format
